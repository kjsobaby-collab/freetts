# 스크립트 작성 규칙

| 문법 | 의미 | 예시 |
|---|---|---|
| `# 제목` | 강의 제목 (읽지 않음) | `# Lecture 3` |
| `## Slide N: 제목` · `[SLIDE N]` · `Slide N. 제목` · `## 제목` | 섹션 구분 → 섹션별 오디오 파일 | `## Slide 2: Intro` |
| `[pause 1s]` · `[pause 500ms]` · `[pause]` | 무음 (길이 생략 시 기본 1초) | `[pause 2s]` |
| `*단어*` | 강조 표시 (Kokoro는 기호만 제거하고 평문으로 읽음) | `*important*` |
| `{표기\|읽기}` | 발음 지정 — 자막엔 표기, 음성은 읽기 | `{SQL\|sequel}` |
| `[speaker: name]` | 이후 문단의 화자 전환 | `[speaker: student]` |
| `[rate 0.9]` | 이후 문단 속도 변경 | `[rate 0.85]` |
| `<!-- ... -->` | 주석 (읽지 않음) | |
| 빈 줄 | 문단 구분 → 문단 사이 쉼 | |

- 첫 섹션 마커 앞의 줄(머리말)은 읽지 않습니다. 첫 줄은 강의 제목으로 사용합니다.
- 숫자·연도·%·통화·약어(e.g., i.e.)·기호(≤, ≈, x^2)는 자동으로 읽기 좋은 영어로 바뀝니다. **정규화 미리보기** 탭에서 확인하세요.
- 계속 틀리게 읽히는 단어는 오른쪽 클릭 → **발음 사전에 추가** 하세요.

## 편집기 단축 동작
- 문장 선택 후 오른쪽 클릭 → **선택 영역 듣기**
- **Ctrl + 더블클릭**: 그 문장부터 재생 (생성된 오디오가 있을 때)
- 재생 중에는 지금 읽는 문장이 노란색으로 표시됩니다.

## 섹션 상태
- ● 완료 · ◐ 생성 중 · ○ 변경됨/미생성 · ✕ 오류
- **변경분만 생성**은 수정되었거나 아직 생성되지 않은 섹션만 합성합니다. 문장 단위 캐시 덕분에 바뀐 문장만 다시 합성됩니다.
